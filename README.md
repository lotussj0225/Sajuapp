# 사주나침반

모바일 환경에 맞춘 사주팔자 리딩 웹앱입니다.

## 기능

- 양력/음력 생년월일시 기준 사주팔자 계산
- 음력 윤달 입력 지원
- 오른쪽부터 년주, 월주, 일주, 시주 순서의 8칸 명식판
- 야자시 23:30-23:59 적용 옵션
- 오행 균형 분석
- 일간 기준 년주/월주/일주/시주 관계 분석
- 십성/육친, 사회관계, 적성 중심 해석
- 총운, 일, 관계, 시기 탭별 확장 해석
- 성별과 연간 음양 기준 대운 순행/역행 계산
- 10년 단위 대운 카드 표시

## 실행

설치 없이 `index.html`을 브라우저에서 열면 됩니다.

로컬 서버로 실행하려면:

```bash
python -m http.server 8765
```

그 다음 브라우저에서 `http://127.0.0.1:8765/index.html`을 엽니다.

## 계산 기준

상세한 목표 계산 기준은 [계산 정책](docs/calculation-policy.md)에 정리되어 있습니다.

현재 `main` 버전에는 다음 한계가 있습니다.

- 24절기의 연도별 정확한 절입 시각 대신 고정 날짜 근사값을 사용합니다.
- 야자시 미적용 시에도 23:30 이후 일주가 다음 날로 바뀌는 동작이 남아 있습니다.
- 성별 미선택 시 대운 방향을 임시로 표시합니다.
- 대운 시작 나이를 정수로 반올림합니다.
- 진태양시, 출생지 경도, 지역 보정은 지원하지 않습니다.

음력 변환은 1900-2050년 범위의 내장 변환표를 사용하며, 해석은 일간 기준 십성/육친 관계를 중심으로 구성합니다. 정확한 절입 시각과 야자시·대운 정책은 계산 엔진 개선 및 검증 후 적용됩니다.
