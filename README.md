# 사주나침반

모바일 환경에 맞춘 사주팔자 리딩 웹앱입니다.

## 기능

- 양력/음력 생년월일시 기준 사주팔자 계산
- 음력 윤달 입력 지원
- 오른쪽부터 년주, 월주, 일주, 시주 순서의 8칸 명식판
- 야자시 23:30-23:59 적용 옵션
- 오행 균형 분석
- 총운, 일, 관계, 시기 탭별 확장 해석
- 성별과 연간 음양 기준 대운 순행/역행 계산
- 10년 단위 대운 카드 표시

## 실행

설치 없이 `index.html`을 브라우저에서 열면 됩니다.

로컬 서버로 실행하려면:

```bash
python -m http.server 8765
```

그 다음 브라우저에서 `http://127.0.0.1:8765/index.html`을 엽니다.

## 계산 기준

현재 버전은 양력/음력 날짜, 24절기 근사값, 야자시 23:30 기준을 사용합니다.
음력 변환은 1900-2050년 범위의 내장 변환표를 사용합니다.
전문 만세력의 절입 시각, 진태양시, 지역 보정과는 차이가 날 수 있습니다.
