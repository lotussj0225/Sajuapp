# 사주나침반 계산 정책

> 상태: 구현 목표 정책 · 사주 전문가 검토 대기
>
> 작성일: 2026-08-01

이 문서는 사주나침반이 어떤 시간·날짜 경계를 사용해 명식과 대운을 계산할지 정의합니다. 현재 `main` 브랜치의 구현과 목표 정책은 아직 일부 다르며, 아래의 "현재 구현과의 차이"에 구분해 기록합니다.

## 1. 기본 원칙

- 기준 시간대는 `Asia/Seoul`(KST, UTC+09:00)입니다.
- 같은 입력과 같은 기준 시각은 브라우저와 운영체제의 로컬 시간대가 달라도 같은 결과를 내야 합니다.
- 계산 사실과 해석 문구를 분리합니다.
- 학파에 따라 달라질 수 있는 기준은 화면과 결과에 사용 여부를 표시합니다.
- 검증되지 않은 임시값으로 년주·월주·대운 방향을 확정하지 않습니다.

## 2. 입력 범위

| 항목 | 정책 |
|---|---|
| 양력 생년월일 | 1900-01-01부터 2050-12-31 |
| 음력 생년월일 | 음력 1900년부터 2050년, 평달·윤달 구분 필수 |
| 출생 시각 | KST 기준 00:00부터 23:59 |
| 성별 | 선택 가능. 미선택 시 대운 방향과 대운표를 계산하지 않음 |
| 출생지 | 이번 릴리스에서는 입력받지 않음 |

음력 입력은 먼저 양력 날짜로 변환한 뒤 네 기둥을 계산합니다. 유효하지 않은 윤달이나 월말 날짜는 결과를 만들지 않고 입력 오류로 처리합니다.

## 3. 네 기둥의 경계

### 년주

년주는 민간 달력의 1월 1일이 아니라 해당 연도의 입춘 절입 시각을 경계로 바뀝니다. 입춘 직전까지는 이전 간지년, 입춘 시각부터는 새 간지년을 사용합니다.

예시 기준값:

- 2024년 입춘: 2024-02-04 17:27 KST
- `2024-02-04 17:26:59`는 계묘년
- `2024-02-04 17:27:00`부터는 갑진년

### 월주

월주는 다음 12개 절입의 정확한 KST 시각을 경계로 바뀝니다.

| 절입 | 태양 황경 | 월지 |
|---|---:|---|
| 소한 | 285° | 축 |
| 입춘 | 315° | 인 |
| 경칩 | 345° | 묘 |
| 청명 | 15° | 진 |
| 입하 | 45° | 사 |
| 망종 | 75° | 오 |
| 소서 | 105° | 미 |
| 입추 | 135° | 신 |
| 백로 | 165° | 유 |
| 한로 | 195° | 술 |
| 입동 | 225° | 해 |
| 대설 | 255° | 자 |

절입 날짜의 00:00에 일괄 변경하지 않고, 해당 연도의 실제 절입 시각 전후를 비교합니다.

### 일주

일주는 KST 민간 날짜의 `00:00`을 경계로 바뀝니다. 야자시 옵션이 켜져 있어도 `23:30-23:59`의 일주 자체는 현재 민간 날짜를 유지합니다.

### 시주와 야자시

| 입력 | 야자시 미적용 | 야자시 적용 |
|---|---|---|
| 23:29 | 현재 날짜의 일간으로 시주 천간 계산 | 현재 날짜의 일간으로 시주 천간 계산 |
| 23:30-23:59 | 현재 날짜의 일간으로 시주 천간 계산 | 다음 날짜의 일간으로 시주 천간 계산 |
| 00:00 이후 | 다음 민간 날짜의 일주·시주 사용 | 다음 민간 날짜의 일주·시주 사용 |

야자시 적용은 `23:30`부터 시주 천간의 기준 일간만 다음 날로 전환합니다. 일주는 민간 날짜가 바뀌는 `00:00`까지 현재 날짜를 유지합니다.

## 4. 대운 정책

### 순행·역행

- 남성은 년간이 양이면 순행, 음이면 역행합니다.
- 여성은 년간이 음이면 순행, 양이면 역행합니다.
- 성별 미선택 시 방향을 임의 추정하지 않고 대운 결과를 보류합니다.

### 시작 시점

- 순행은 출생 시각부터 다음 절입까지의 차이를 사용합니다.
- 역행은 출생 시각부터 이전 절입까지의 차이를 사용합니다.
- 시간 차이는 `3일 = 1년`, `1일 = 4개월`로 환산합니다.
- 정수 나이로 반올림하지 않고 `N년 M개월`로 보존합니다.
- 대운의 달력 기간은 `출생연도 + 정수 나이`로 단순 계산하지 않고 실제 시작 시점을 기준으로 계산합니다.

이 절의 순행·역행 및 환산법은 학파 의존성이 있으므로 외부 검토가 완료되기 전까지 배포 게이트로 취급합니다.

## 5. 해석 범위

- 오행 수치는 우선 천간과 지지의 표면 글자 분포로 표시합니다.
- 지지는 본기와 전체 지장간을 구분해 보여 줍니다.
- 학파별 가중치를 합의하지 않은 상태에서 지장간에 임의 비율을 부여하지 않습니다.
- 최고 점수가 같은 십성은 하나만 대표값으로 선택하지 않고 모두 표시합니다.
- 진태양시, 출생지 경도, 서머타임, 용신·격국의 학파별 판단은 이번 릴리스에서 지원하지 않습니다.
- 해석은 참고용이며 건강·법률·재무 등 중요한 결정의 단독 근거로 사용하지 않도록 안내합니다.

## 6. 현재 구현과의 차이

| 영역 | 현재 `main` 구현 | 목표 정책 | 적용 단계 |
|---|---|---|---|
| 절입 | 해마다 같은 날짜의 00:00으로 근사 | 실제 연도별 KST 절입 시각 | 개선 계획 Task 4 |
| 년주 | 2월 4일 날짜만 비교 | 실제 입춘 시각 비교 | 개선 계획 Task 4 |
| 월주 | 12개 고정 날짜 비교 | 12개 실제 절입 시각 비교 | 개선 계획 Task 4 |
| 야자시 미적용 | 23:30부터 일주를 다음 날로 변경 | 00:00까지 현재 날짜 유지 | 개선 계획 Task 4 |
| 성별 미선택 대운 | 년간 음양으로 임시 방향 표시 | 대운 계산 보류 | 개선 계획 Task 4 |
| 대운 시작 | 일수 차이를 정수 나이로 반올림 | 년·개월로 보존 | 개선 계획 Task 4 |
| 오행 표시 | `오행 균형`으로 표시 | `표면 오행 분포`로 명시 | 개선 계획 Task 5 |

따라서 이 문서는 현재 앱이 이미 정확한 절입 계산을 제공한다는 의미가 아닙니다. 위 차이가 구현되고 검증되기 전까지 README와 화면에는 현재 계산의 한계를 함께 표시해야 합니다.

## 7. 검증 기준

- 한국천문연구원 달력자료의 2024-2028년 12개 절입 60건과 비교합니다.
- 계산값과 공식 절입 시각의 차이는 2분 이내여야 합니다.
- 허용치를 넘는 값은 배포를 중단하고 공식 시각 override와 출처를 기록합니다.
- 일진·음력 변환은 한국천문연구원 음양력 정보와 대조합니다.
- 1900, 2000, 2050 경계와 1900-2050의 모든 윤달을 회귀 테스트에 포함합니다.
- 23:29, 23:30, 23:59, 00:00 야자시 경계를 자동 테스트합니다.

검증 자료:

- [한국천문연구원 달력자료](https://astro.kasi.re.kr/kor/life/post/calendarData)
- [공공데이터포털 한국천문연구원 음양력 정보 API](https://www.data.go.kr/data/15012679/openapi.do)
