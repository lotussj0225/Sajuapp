## 당시 설명에서 발견된 충돌과 결정

### 야자시 OFF 동작

원채팅에서 사용자는 “야자시 적용”을 요청했고, 당시 어시스턴트는 `23:30-23:59`에 일주는 입력 날짜, 시주는 다음 날 일간 기준으로 계산한다고 설명했습니다. 그러나 OFF일 때 오히려 다음 날 일주로 계산한다고 설명했고 현재 코드도 이 동작을 포함합니다.

사용자 요청은 옵션 제공까지이며 OFF의 역전 동작을 요구한 것은 아닙니다. 따라서 [계산 정책](calculation-policy.md)에 따라 다음처럼 정리합니다.

- OFF: 00:00 전까지 일주와 시주 천간 모두 현재 날짜 기준
- ON: 23:30부터 시주 천간만 다음 날짜 일간 기준
- 일주는 ON/OFF 모두 00:00에 변경

### 음력 지원 범위

당시 구현 예고에서는 1900-2100년을 언급했지만 완료 보고와 실제 내장 변환표는 1900-2050년입니다. 사용자는 연도 범위를 지정하지 않고 양력·음력 지원을 요청했습니다.

이번 개선 범위는 검증 가능한 1900-2050년으로 고정합니다. 2051-2100 확장은 정확한 변환 자료와 KASI 대조 세트를 확보한 뒤 별도 계획으로 진행합니다.

### 해석 정보의 출처

현재 해석은 외부 사주 API나 실시간 데이터베이스를 호출하지 않고 브라우저 내부 규칙과 문구로 생성됩니다. 원채팅의 “어디서 정보를 가져오는가”라는 질문에 대응해 다음 내용을 화면과 README에 공개해야 합니다.

- 사용한 계산 기준과 지원 범위
- KASI로 검증하는 달력·절입 데이터
- 규칙 기반 해석임을 알리는 문구
- 지장간·십성 등 실제로 반영한 요소
- 진태양시·출생지·학파별 용신처럼 반영하지 않은 요소

### 대운 기준

당시 대운은 고정 절기 날짜와 `날짜 차이 ÷ 3`의 정수 반올림으로 구현됐습니다. 기능 요구는 유지하되 Task 4에서 실제 절입 시각, 년·개월 보존, 성별 미선택 시 계산 보류로 정확성과 설명 가능성을 높입니다.
